An add-on for EternalHUD that displays item value per slot and total value. 
Code made by GPT-6 Astra and tester is me (partly).

## Features

- Shows value per slot below the reference price, based on the item's current inventory size. Folding a weapon updates its value per slot.
- Shows total value for containers, armor, helmets, and weapons. The total includes the item itself, nested contents, attachments, chambered rounds, and ammunition in magazines. Mixed ammunition is counted by type and quantity.
- Excludes fixed, built-in armor inserts from the total. Removable plates are included.
- Displays prices as rounded whole numbers.

## Installation

1. Install EternalHUD. Link: https://sns.oddba.cn/article/LwLcCFfftL9
2. Download `EternalHUD.SlotValue.dll` from Assets below.
3. Place the DLL in your SPTushonka `BepInEx/plugins/` folder and restart the game client.
